# CB4 — Odin Android game

Игра перенесена с C на **Odin**. Это нативный Android `NativeActivity` без Java-части:

- игровой цикл и обработка touch-событий находятся в `src/*.odin`;
- рендерер рисует прямо в `ANativeWindow_Buffer` и не требует SDL/OpenGL;
- Android NDK glue остаётся только платформенным C-мостом, который компилируется из NDK в CI;
- `.github/workflows/main.yml` скачивает закреплённую версию Odin, собирает `arm64-v8a` и `armeabi-v7a`, а затем создаёт подписанный APK.

## Управление

Левый виртуальный джойстик двигает корабль. Кнопка `ATTACK` выпускает один снаряд в направлении последнего движения. Игра сохраняет управление и во время поворота экрана/пересоздания `ANativeWindow`.

## Сборка

Полная сборка запускается через GitHub Actions (`push` или `workflow_dispatch`). Для локальной сборки нужны Odin, Android SDK и NDK r25c; workflow содержит все команды, включая упаковку APK.
